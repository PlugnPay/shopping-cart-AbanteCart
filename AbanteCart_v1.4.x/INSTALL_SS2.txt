====================================================
PlugnPay Smart Screens v2 Module (Hosted Payments)
Payment Extension for AbanteCart v1.4.x — v1.0.3
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

This module redirects customers to PlugnPay Smart Screens v2 hosted
billing pages (https://pay1.plugnpay.com/pay/). Your store does not
collect card data onsite.

Transactions are AUTHORIZATION-ONLY (pb_post_auth=no). Orders are
left Pending. Capture, void, and refund are performed in PlugnPay
Merchant Admin — not from AbanteCart.

Requires AbanteCart 1.4.x and PHP 8.2+.
There is no public demo gateway account. Use merchant-supplied
credentials from your PlugnPay account.

v1.0.3 notes (authenticated gateway return):
- Callback requires PlugnPay's server-secret Response Verification Hash
  (configure SHA-256 when available)
- Session IDs are not placed in callback URLs
- Payment method, amount, currency, account, and one-time session binding
  all fail closed
If you previously installed v1.0.2, re-upload this package and configure
the Response Verification Hash before re-enabling the payment method.

v1.0.1 notes (AbanteCart 1.4.x routing):
- Return URL uses rt=r/extension/plugnpay_ss2/callback
- Success completes via checkout/finalize
- Declines return to checkout/fast_checkout
If you previously installed v1.0.0, re-upload this package
(or overwrite the extension files) so the return no longer 404s.
***************************

To Install (Admin upload — recommended):

1. Use abantecart_1.4_ss2_module.tar.gz
   (AbanteCart requires .tar.gz for package upload — .zip will fail).

2. Admin → Extensions → Install Extension → Extension Upload
   → browse to abantecart_1.4_ss2_module.tar.gz → Continue → accept license.

3. Admin → Extensions → Payments → enable "PlugnPay Smart Screens v2".

4. In PlugnPay Security Administration, enable the outbound Response
   Verification Hash and choose SHA-256 when available.

5. Enter Gateway Account and the matching Response Verification Hash.
   Configure currency, database storage, and debug logging as needed.

6. Ensure the secure session cookie uses SameSite=None for the cross-site
   POST return. Do not pass session IDs in callback URLs.

7. Place a test order using your merchant account / PlugnPay test
   procedures. After approval you should land on checkout/finalize.

Manual FTP install (optional):

1. Copy from the development tree into your AbanteCart root:
     AbanteCart_v1.4.x/src/extensions/plugnpay_ss2/
       → <shop>/extensions/plugnpay_ss2/

2. Then enable under Admin → Extensions → Payments as above.
